# ESCALA-DE-CAPRINI

Calculadora interactiva de la escala de Caprini para apoyar la evaluación del riesgo de tromboembolismo venoso en adultos.

## Uso

Abre [index.html](index.html) en el navegador o sirve la carpeta del repositorio como página web:

```bash
python3 -m http.server 8000
```

Luego visita <http://localhost:8000>.

La calculadora suma edad, cirugía, movilidad reducida y factores clínicos. Es una herramienta de apoyo y no sustituye la valoración profesional ni los protocolos institucionales.
